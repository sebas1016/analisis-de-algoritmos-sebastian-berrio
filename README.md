# Curso - Analisis de Algoritmos
En este curso, aprendemeros a identificar deficiencias en los algoritmos, midiendo el tiempo, y la memoria 
que se necesita para funcionar con diferentes tipos de datos. De esta manera mejoramos la eficiencia del codigo.

## Objetivos

* **Tiempo:** Cuenta cuántas operaciones hace el programa según el tamaño de los datos de entrada. 
* **Espacio:** Mide cuánta memoria RAM o almacenamiento ocupa el proceso.

## Notación Big O
* Es una forma matemática de escribir cómo crece el tiempo o la memoria cuando los datos aumentan mucho.
* Sirve para comparar de forma sencilla si un algoritmo es rápido (O(1), \(O(\log n)\), O(n)) o muy lento (O(n²), \(O(2^n)\)).

## Desarrollo.
El curso tendra 3 secciones Laboratio/, ejercicios-clase/ y benchmarks/. Cada seccion o modulo tendra su objetivo.

## Estructura del Proyecto

El repositorio está organizado en las siguientes carpetas para mantener un flujo de trabajo limpio y modular:

*   **`laboratorios/`**: Contiene una carpeta específica para cada uno de los cinco informes de laboratorio evaluativos del curso.
*   **`ejercicios-clase/`**: Código fuente de las sesiones prácticas no evaluativas, incluyendo los retos de programación en Python.
*   **`benchmarks/`**: Scripts compartidos de medición de tiempos de ejecución y herramientas de graficación para los análisis empíricos.
